# Portfolio site

The source of my personal site: https://mithuncreates99.github.io

Built with React 19, TypeScript and Vite. The animations use GSAP and Framer Motion.

## Run it

Needs Node.js 20 or newer.

```bash
npm install
npm run dev
```

Other scripts: `npm run build` (type-check and production build), `npm run preview`, `npm run lint` (oxlint).
